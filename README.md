<h2>Bitverter - Projeto de estudo</h2>

<br />

<h3>🎯 Objetivo</h3>

O Bitverter foi um dos meus projetos iniciais, desenvolvido para exercitar a lógica de programação e o consumo de serviços externos.

A aplicação tem como função principal converter valores de moedas fiduciárias e listar suas respectivas cotações em relação ao Bitcoin.

Através de uma interface simples e funcional, o projeto foca na manipulação do DOM e na integração com APIs financeiras, permitindo que o usuário entenda o poder de compra de diferentes moedas no mercado de criptoativos de forma instantânea.

<br />

<h3>🛠️ Construído com:</h3>

<ul>

  <li>JavaScript (ES6) - Lógica de conversão e consumo de API</li>

  <li>HTML5 - Estrutura semântica da aplicação</li>

  <li>CSS3 - Estilização e layout da interface</li>

  <li>Fetch API - Requisição de dados assíncronos para cotações em tempo real</li>

</ul>

<br />
